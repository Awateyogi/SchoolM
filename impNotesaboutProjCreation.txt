2.Models
User.cs → stores user properties (username, password hash, role)
Student.cs → stores student info (name, email, class)
3.Repositories
UserRepository.cs → database access for Users
StudentRepository.cs → database access for Students(calls stored procedures)
4.Services
TokenService.cs → JWT token generation
